# GrounUp Brand Reference

Extracted directly from the official logo files (`logos/`) by sampling the actual rendered pixels at 600 DPI — not guessed or approximated.

## Logo files

- **GrounUp-Logo-Wordmark-v1** — horizontal wordmark. "GROUN" in black, "UP" in gold, with a stylized "G" containing a circular arrow/motion cutout.
- **GrounUp-Logo-Stacked-v2** — stacked mark. Large black "G" with a gold arrow sweeping through it, wordmark below in the same black/gold split.

Both ship as vector PDF (scalable, print-ready) and a 600 DPI PNG export (screen/web use) in `logos/`.

## Verified brand colors

| Role | Hex | RGB | Notes |
|---|---|---|---|
| Primary black | `#000000` | 0, 0, 0 | "GROUN" / the "G" body |
| Primary gold | `#F6C101` | 246, 193, 1 | "UP" / the arrow motif — this is the accent color, not a generic yellow |
| Background | `#FFFFFF` | 255, 255, 255 | Logo is designed for a white/light background |

## Guidance for future GrounUp Enterprise materials

The Master Specification and Requirements Register built earlier in this project used a generic dark-teal accent (the platform's default palette) because no brand direction existed yet at that time. **Now that real brand colors exist, any new GrounUp-facing document, deck, or web asset should use `#000000` and `#F6C101` as the primary palette** instead of the generic default, to stay consistent with the actual logo. Existing v1.0/v2.0 documents were not retroactively re-themed — only mention this if asked, or re-theme on the next substantive revision of those files.
