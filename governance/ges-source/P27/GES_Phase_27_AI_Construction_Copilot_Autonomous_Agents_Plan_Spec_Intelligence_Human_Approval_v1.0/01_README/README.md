# GES Phase 27 - AI Construction Copilot, Autonomous Agents, Plan/Spec Intelligence & Human Approval

Version: 1.0.0
Status: Implementation-ready specification

Phase 27 implements the governed AI layer above GrounUp's deterministic Phase 26 estimating engine.

Controlled package:
- 480 requirements
- 480 mapped tests
- 36 AI/agent modules
- 40 AI governance/runtime entities
- 28 API contracts
- 23 event contracts
- 28 business rules
- 14 security controls
- 16 quality gates
- 12 controlled evaluation definitions
- provider-neutral starter code

Non-negotiable boundaries:
- Phase 26 remains authoritative for estimate arithmetic.
- Phase 25 remains authoritative for governed library publication.
- AI must preserve source evidence and uncertainty.
- Protected writes/approvals require human authorization according to tool risk policy.
- AI cannot override safety, legal/commercial, security, estimate-freeze, or enterprise-lock authority.
- Agent retrieval/tool access cannot exceed the requesting actor's permitted scope.
