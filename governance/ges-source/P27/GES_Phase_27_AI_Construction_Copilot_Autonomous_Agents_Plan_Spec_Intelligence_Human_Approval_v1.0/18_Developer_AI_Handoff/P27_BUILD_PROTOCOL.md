# Phase 27 Build Protocol

1. Implement model/provider abstraction, prompt/model registry and AI audit trace.
2. Implement permission-aware evidence retrieval and citation service.
3. Implement tool registry and default-deny tool policy before autonomous agents.
4. Connect read-only Phase 25 libraries and Phase 26 deterministic calculation tools.
5. Implement human approval service for protected tool risk classes.
6. Implement copilot gateway and context builder.
7. Implement plan/spec/scope/quantity/service-mapping agents.
8. Implement estimate-review, risk, conflict and missing-information agents.
9. Add agent orchestration with bounded tool/cost/time limits and cancellation.
10. Implement evaluation datasets, regression gates, fallback and kill switch.
11. Add background agents only after tool policy, approval, isolation and evaluation gates pass.
12. Do not grant AI authority to approve estimates, publish library records, make legal/safety decisions, or bypass Phase 20/22 governance.
