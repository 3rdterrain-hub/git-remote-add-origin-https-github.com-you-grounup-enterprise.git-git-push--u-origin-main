# Deployment Guide

1. Deploy tenant-scoped CRM services and event contracts.
2. Configure identity, permission, retention, consent, brand, territory, stage, score, and approval policies.
3. Connect communication, advertising, website, estimating, project, accounting, signature, and portal services.
4. Load controlled statuses, templates, reason codes, scoring factors, and report definitions.
5. Execute migration, reconciliation, tenant-isolation, security, workflow, performance, mobile, and UAT tests.
6. Approve gates, tag `GES-P08-v1.0.0`, publish the manifest, and prohibit uncontrolled changes.
