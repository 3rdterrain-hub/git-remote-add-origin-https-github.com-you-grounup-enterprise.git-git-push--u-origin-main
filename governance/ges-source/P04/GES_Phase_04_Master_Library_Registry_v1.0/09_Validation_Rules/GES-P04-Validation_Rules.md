# Validation Rules

- **VR-001** `item_code`: Required; unique within tenant/library/effective period (Error)
- **VR-002** `name`: Required; 2-200 characters (Error)
- **VR-003** `version`: Must follow semantic version format (Error)
- **VR-004** `confidence_score`: Must be between 0 and 1 inclusive (Error)
- **VR-005** `effective_from`: Required for Approved or Active records (Error)
- **VR-006** `effective_to`: Must be later than effective_from (Error)
- **VR-007** `approved_by`: Required when approval_status is Approved (Error)
- **VR-008** `approved_at`: Required when approval_status is Approved (Error)
- **VR-009** `unit_id`: Must exist and be active when the library is quantity-bearing (Error)
- **VR-010** `source_reference`: Required for costs, rates, formulas, standards and AI knowledge (Error)
- **VR-011** `tenant_id`: Required for Tenant-scoped libraries and prohibited for Global-only records (Error)
- **VR-012** `relationships`: All target IDs must exist and pass scope access checks (Error)
- **VR-013** `status`: Archived records cannot return to Active without a new version (Error)
- **VR-014** `white_label_visibility`: Must align with tenant and reseller access policy (Error)
- **VR-015** `custom_fields`: Must validate against the tenant extension schema (Error)
- **VR-016** `audit_hash`: Must match canonicalized approved payload (Error)
- **VR-017** `keywords`: Maximum 100 unique normalized keywords (Warning)
- **VR-018** `description`: Recommended minimum 25 characters for approved records (Warning)
- **VR-019** `effective period`: Overlapping active periods for same code are prohibited (Error)
- **VR-020** `duplicate similarity`: Similarity >= 0.90 requires explicit duplicate disposition (Warning)
