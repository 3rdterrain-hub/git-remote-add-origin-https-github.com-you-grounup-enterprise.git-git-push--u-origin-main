# Entity Definitions

## LibraryDefinition
Defines a governed library, scope, ownership and lifecycle.

## LibraryItem
Canonical versioned record contained by a library.

## LibraryItemVersion
Immutable approved snapshot.

## LibraryRelationship
Typed dependency between items.

## LibraryApproval
Review and approval decision.

## LibraryImportBatch
Staged bulk import with validation results.

## TenantOverride
Permitted tenant-specific override of an inherited record.

## SourceProvenance
Evidence and source trail for a record.
