# Example - Subdivision Plan Intelligence Workflow

1. Document Intelligence Agent classifies plan sheets, specifications, addenda, and reports.
2. Takeoff Agent identifies measurable work and creates traceable quantities.
3. Estimating Agent maps quantities to governed services, resources, and assemblies.
4. Production Agent recommends crews, equipment, trucking, fuel, and duration.
5. Risk Agent flags conflicts, exclusions, missing geotechnical information, and uncertain assumptions.
6. Scheduling Agent creates a preliminary sequence and milestone forecast.
7. Human estimator reviews and approves before estimate writeback.
8. Canonical APIs save approved records with source citations and audit history.
