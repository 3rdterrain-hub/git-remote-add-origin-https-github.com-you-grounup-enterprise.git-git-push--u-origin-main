# Phase 02 Reports

- **RPT-P02-001 Platform Health Summary** - Availability, latency, errors, dependencies, queue health, and incidents
- **RPT-P02-002 Tenant Provisioning Report** - Provisioning duration, resources, validation, failures, and rollback status
- **RPT-P02-003 API Usage and Reliability** - Requests, latency, errors, throttling, versions, consumers, and deprecations
- **RPT-P02-004 Job and Workflow Performance** - Volume, duration, retries, failure, dead letters, waiting states, and SLA breaches
- **RPT-P02-005 File and Search Operations** - Uploads, scans, quarantine, storage, indexing latency, search volume, and zero-result queries
- **RPT-P02-006 Integration Health** - Connector runs, webhook delivery, event lag, import/export results, and credential expiry
- **RPT-P02-007 Mobile Offline Operations** - Pack downloads, sync latency, rejected changes, conflicts, device risks, and expired packs
- **RPT-P02-008 Security and Resilience** - Session risk, blocked requests, secret rotation, backup status, restore tests, and DR readiness
- **RPT-P02-009 AI Platform Usage** - Executions, models, agents, tokens, tools, cost, errors, evaluation status, and blocked actions
- **RPT-P02-010 Localization and Conversion Audit** - Unit and currency conversions, sources, precision, failures, and exception rates
