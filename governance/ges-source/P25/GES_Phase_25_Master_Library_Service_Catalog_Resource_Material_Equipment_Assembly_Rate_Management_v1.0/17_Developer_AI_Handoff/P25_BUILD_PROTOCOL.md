# Phase 25 Build Protocol

1. Implement common library record/version lifecycle first.
2. Implement units/conversions and dependency validation.
3. Implement service catalog and resource libraries.
4. Implement assemblies and component graph validation.
5. Implement labor/equipment/material/truck/subcontract/disposal rate records.
6. Implement regional profiles, source precedence and tenant overrides.
7. Implement publish/effective-date resolver.
8. Implement immutable estimator snapshots.
9. Implement import preview/commit.
10. Implement AI proposal-only writeback and human approval boundary.
11. Implement estimator gateway/query contracts.
12. Run isolation, version, unit, dependency, snapshot, import, AI-writeback and performance gates before Phase 26 estimator uses the libraries.
