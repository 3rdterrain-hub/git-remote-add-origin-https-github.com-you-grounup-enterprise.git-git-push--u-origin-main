# Phase 24 Build Protocol
1. Implement request context and correlation first.
2. Implement authentication adapter and tenant resolution.
3. Implement default-deny authorization and entitlement checks.
4. Implement tenant-aware data repository contracts and negative isolation tests.
5. Implement audit ledger and domain-event outbox.
6. Implement API kernel: validation, errors, pagination/versioning and idempotency.
7. Implement workflow/approval kernel.
8. Implement configuration, feature flags and white-label config boundaries.
9. Implement observability and health/readiness.
10. Run security, migration, contract, E2E and traceability gates.
11. Do not begin dependent domain modules until the relevant platform contracts are accepted.
