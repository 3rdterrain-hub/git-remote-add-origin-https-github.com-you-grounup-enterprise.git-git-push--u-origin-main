# Engine Specifications

| Engine ID | Engine | Purpose |
| --- | --- | --- |
| P07-ENG-001 | Project Lifecycle Engine | Controls project states, gates, required artifacts, waivers, and transitions. |
| P07-ENG-002 | Command Center Aggregation Engine | Assembles role-specific project health, alerts, approvals, KPIs, and actions. |
| P07-ENG-003 | CPM Scheduling Engine | Calculates early/late dates, float, critical path, calendars, constraints, and baselines. |
| P07-ENG-004 | Look-Ahead and Constraint Engine | Builds rolling plans and tracks constraint readiness. |
| P07-ENG-005 | Resource Leveling Engine | Detects conflicts and recommends labor/equipment/crew allocation options. |
| P07-ENG-006 | Field Capture and Posting Engine | Validates and posts daily labor, equipment, production, weather, and delivery data. |
| P07-ENG-007 | Document Control Engine | Manages numbering, revisions, transmittals, review cycles, acknowledgements, and supersession. |
| P07-ENG-008 | RFI and Submittal Engine | Controls registers, due dates, workflows, impacts, and response cycles. |
| P07-ENG-009 | Change Intelligence Engine | Links scope changes to estimate, budget, schedule, contract, and forecast impacts. |
| P07-ENG-010 | Project Cost Control Engine | Maintains budget, commitments, actuals, forecast, variance, and cost-to-complete. |
| P07-ENG-011 | Billing and Retainage Engine | Calculates progress billing, stored material, retainage, and payment status. |
| P07-ENG-012 | Procurement and Lead-Time Engine | Tracks buyout, procurement status, lead times, required-on-site dates, and delivery risk. |
| P07-ENG-013 | Quality Control Engine | Executes inspection plans, checklists, deficiencies, corrective actions, and punch lists. |
| P07-ENG-014 | Safety Control Engine | Manages plans, JHAs, talks, observations, incidents, and corrective actions. |
| P07-ENG-015 | Digital Twin Synchronization Engine | Creates time-stamped, source-aware operational snapshots and freshness indicators. |
| P07-ENG-016 | Project Risk Scoring Engine | Scores cost, schedule, safety, quality, procurement, and documentation risk. |
| P07-ENG-017 | Forecast and Scenario Engine | Produces EAC, ETC, cash flow, completion, and recovery scenarios. |
| P07-ENG-018 | Mobile Offline Sync Engine | Scopes, encrypts, validates, reconciles, and audits offline data synchronization. |
| P07-ENG-019 | Notification and Escalation Engine | Applies subscriptions, severity, SLA, digest, escalation, and acknowledgement logic. |
| P07-ENG-020 | Project Audit and Reconciliation Engine | Detects cross-module mismatches and maintains immutable transaction evidence. |
