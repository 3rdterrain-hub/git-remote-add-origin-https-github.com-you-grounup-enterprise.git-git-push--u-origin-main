# Deployment Guide

Phase 07 is deployed as a multi-tenant SaaS capability behind the GrounUp identity, authorization, audit, API gateway, event bus, file service, search, notification, and AI-platform controls. Recommended rollout: sandbox configuration, master-data validation, pilot project, field/mobile pilot, financial reconciliation, integration cutover, training, controlled production release, and hypercare. White-label tenants use configuration for brand, domain, terminology, email, portal, templates, and enabled modules without forking the core codebase.
