# Mobile and Offline Specification

The field application shall support iOS, Android, and tablet layouts with secure offline capture for assigned projects. Offline packages are scope-limited, encrypted at rest, expiring, and remotely revocable. Users can capture daily reports, time, equipment, production, inspections, incidents, deliveries, photos, signatures, and voice notes. Synchronization applies schema validation, authorization, malware checks, optimistic concurrency, duplicate detection, and explicit conflict resolution.
