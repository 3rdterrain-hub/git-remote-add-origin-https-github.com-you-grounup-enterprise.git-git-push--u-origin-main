## Experience standards
- Role-first navigation with a universal project context bar.
- Progressive disclosure so field and small-contractor users are not overwhelmed.
- Configurable terminology, custom fields, forms, dashboards, colors, logos, domains, email templates, and portal branding.
- Keyboard, touch, voice, and accessible interaction patterns.
- Clear offline, synchronization, stale-data, approval, and AI-confidence indicators.
