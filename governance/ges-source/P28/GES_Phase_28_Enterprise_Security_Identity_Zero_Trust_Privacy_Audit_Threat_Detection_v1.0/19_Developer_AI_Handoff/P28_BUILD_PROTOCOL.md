# Phase 28 Build Protocol

1. Implement/default-deny identity and policy decision/enforcement paths before privileged functionality.
2. Prove tenant isolation across API, data, search, files, cache, events and AI.
3. Implement MFA/step-up and JIT privileged elevation with expiry/revocation.
4. Implement service identity ownership and managed credential-reference rotation.
5. Implement data classification, retention/deletion and encryption policy hooks.
6. Integrate managed key/secret/certificate providers behind portable adapters.
7. Add secure SDLC vulnerability/secret/dependency/container/IaC gates.
8. Build security telemetry, detection, alerts and incident workflows.
9. Implement access reviews, SoD and time-bound security exceptions.
10. Validate AI security policy and prompt/tool boundaries from Phase 27.
11. Run threat-model, tenant-isolation, authz, injection, incident and recovery benchmarks.
12. Do not mark production security accepted until Phase 20/22 production/security gates are actually approved.
