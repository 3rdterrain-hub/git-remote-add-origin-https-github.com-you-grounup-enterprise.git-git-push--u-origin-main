# Phase 23 Developer / AI Build Protocol

1. Start from an approved backlog item and GES requirement IDs.
2. Read the source phase artifacts and Phase 22 execution controls.
3. Identify component/API/event/data impacts.
4. Create or reference an ADR for any new architecture decision.
5. Do not invent missing governed business logic.
6. Implement tenant/security/audit boundaries before feature behavior.
7. Implement code, migrations, tests, observability and documentation together.
8. Run quality gates and AI evaluations where applicable.
9. Update traceability and evidence.
10. Human reviewers approve protected business/security/AI/release decisions.
11. Promote only through controlled environments.
12. Production remains subject to Phase 20 readiness and Phase 22 final gates.
