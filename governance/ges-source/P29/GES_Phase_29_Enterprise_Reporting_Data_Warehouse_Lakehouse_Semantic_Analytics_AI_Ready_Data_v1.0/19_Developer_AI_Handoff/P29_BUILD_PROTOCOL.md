3. Implement raw, validated and curated analytical layers.
4. Implement quality, reconciliation, freshness and lineage before executive reporting.
5. Build conformed dimensions/facts and historical SCD behavior.
6. Implement certified semantic model and metric/KPI registry with golden tests.
7. Implement tenant/row/column security before dashboards/self-service.
8. Build domain marts and executive/operational dashboards.
9. Implement controlled report scheduling/exports/subscriptions.
10. Implement forecasting/scenarios/benchmarks with explicit assumptions and labeling.
11. Implement AI-ready feature snapshots and embedding provenance with point-in-time/security controls.
12. Run historical reproduction, quality, security, performance and incident/backfill tests before certifying outputs.
